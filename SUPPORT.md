# Support

This is a community-maintained, self-hosted project without a support service-level agreement.

Before asking for help:

1. Check the README, the documents under `docs/`, and existing issues.
2. Reproduce the problem on the latest `main` revision when practical.
3. Remove tokens, private Slack content, user identifiers, and local paths from logs.

Use the bug report form for reproducible defects, the feature request form for proposed improvements, and the usage-question form for configuration or operation help.

Report security vulnerabilities through the process in [SECURITY.md](SECURITY.md), never through a public issue.
